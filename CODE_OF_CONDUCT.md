# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The full text is at that link; the short version is below.

## The standard

Everyone taking part in this project — issues, pull requests, discussions, reviews — is expected
to behave in a way that makes other people want to keep taking part. Concretely:

- Be civil about code. Review the change, not the person who wrote it. "This breaks determinism
  under load, here's the case" is useful; "this is amateur work" is not.
- Assume competence and good faith. Contributors arrive with different backgrounds — automotive,
  embedded, Python, build systems — and nobody knows all of it. Explain rather than sneer.
- Accept that disagreement is normal and resolvable with evidence. This is a testing platform;
  "run it and show me" settles most arguments.
- Harassment, personal attacks, discriminatory language, and unwelcome personal attention are
  not acceptable in any form or venue connected to the project.

## Scope

This applies in all project spaces, and when you are representing the project elsewhere.

## Enforcement

Report conduct problems to **alexander.guenther@tuta.io**. Reports are handled privately, and
the reporter's identity is not shared.

This is a single-maintainer project, so enforcement is proportionate rather than procedural:
expect a conversation first for anything ambiguous, and removal from the project's spaces for
anything that isn't. The maintainer makes the call, applies it to themselves as well, and will
explain the reasoning if asked.
